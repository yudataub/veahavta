# ספריית ואהבת

https://yudataub.github.io/veahavta/

קטלוג אודיו של שיעורים והרצאות על זוגיות ואינטימיות, לפי מרצים ונושאים, עם נגן מובנה.
הקבצים בריפואי מדיה נפרדים (`yudataub/veahavta-a01` ...), עד ~900MB כל אחד.

- `index.html` — הקטלוג והנגן; `data.js` — נוצר אוטומטית
- `tools/publish.py` — מעתיק מ-`G:\...\ואהבת`, מעלה ובונה את `data.js`
- `tools/topics.py` — הנושאים וחוקי הסיווג. שינוי שם ואז `python tools/publish.py catalog` — בלי העלאה מחדש
- `tools/old_catalog_map.json` — המיון מהקטלוג הישן ("📚 ספריית ואהבת.html"), בסיס הסיווג

אודיו בלבד; כפילויות (אותו שם+גודל) עולות פעם אחת; קבצים מעל 95MB לא עולים.
